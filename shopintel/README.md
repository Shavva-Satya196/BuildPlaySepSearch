# ShopySearch AI

MVP AI Shopping Intelligence Agent using Next.js + SerpApi.

## Features
- Natural-language shopping query
- Live Google Shopping search through SerpApi
- India localization (`gl=in`)
- Budget/RAM/storage/GPU requirement extraction
- Evidence-first requirement checks
- Match ranking

## Run
1. `cp .env.example .env.local`
2. Put your SerpApi key in `.env.local`
3. `npm install`
4. `npm run dev`
5. Open `http://localhost:3000`
